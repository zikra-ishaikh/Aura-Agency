AuraAgency Template Documentation

Thank you for purchasing **AuraAgency**. This guide helps you set up, customize, and configure your new template quickly.

Note: AuraAgency is built using Next.js 16+ (App Router), React 19, and Tailwind CSS v4. Ensure you have Node.js 20.9.0 or higher installed on your computer before proceeding.

Getting Started & Installation

Follow these quick commands in your terminal to boot up the template local server:

1. Install Dependencies

Navigate to the template directory and install the necessary package node modules:

npm install

2. Run Development Server

Boot up the Next.js Turbopack compiler development environment:

npm run dev

Now, open http://localhost:3000 in your browser to inspect the application live preview.

3. Build for Production

Compile and optimize the template code for production deployment hosting:

npm run build

Folder Structure

The project follows a clean directories decoupling layout:

src/
├── app/
│   ├── actions.ts           # Form validation Server Action
│   ├── globals.css          # Global CSS stylesheet & Tailwind theme variables

│   ├── page.tsx             # Home landing hero page
│   ├── about/page.tsx       # Studio philosophy and team grid page

│   │   └── magnetic.tsx     # Cursor pulling animation wrapper
│   └── marketing/           # Sections blocks wrapping UI elements
│       ├── navbar.tsx       # Glassmorphism navigation header
│       ├── footer.tsx       # Semantic footer layout
│       └── bento-grid.tsx   # Capabilities grid component

Customization Guide

Configure branding colors, visual typography details, and logo properties to match your brand style:

How to Change Branding Colors

AuraAgency styles are managed using native CSS-first variables in Tailwind CSS v4. Open src/app/globals.css and customize the theme tokens:

@theme {
  --color-zinc-black: #09090b;       /* Change canvas background */
  --color-primary-purple: #a855f7;   /* Change primary purple accent button glow */
  --color-secondary-cyan: #06b6d4;   /* Change secondary cyan complementary accent */
  --color-glass-card: rgba(24, 24, 27, 0.65);
  --color-glass-border: rgba(255, 255, 255, 0.08);
}

How to Change Logo Text & Branding Icon

Open src/components/marketing/navbar.tsx and look for the logo section:

<Link href="/" className="flex items-center gap-2 group">
  <div className="w-8 h-8 rounded-lg bg-gradient-to-br from-primary-purple to-secondary-cyan flex items-center justify-center relative overflow-hidden">
    <Sparkles className="w-4 h-4 text-white" />
  </div>
  <span className="text-xl font-bold tracking-tight text-white">
    YourLogo<span className="text-transparent bg-clip-text bg-gradient-to-r from-primary-purple to-secondary-cyan">Brand</span>
  </span>
</Link>

Replace YourLogo and Brand text strings with your company name.

How to Update Navigation Links

Open src/components/marketing/navbar.tsx and edit the link items array:

const navLinks = [
  { name: 'Home', href: '/' },
  { name: 'About', href: '/about' },
  { name: 'Contact', href: '/contact' }
];

Key Features Included

  • React 19 Server Actions: Built-in contact form validations using native actions and progressive forms structure.
  • Tailwind CSS v4: Utilizing CSS theme variables for fast compiling and modifications.
  • Spotlight mouse tracking: Interactive hover grid cards drawing radial flares relative to mouse coordinates.
  • Physical magnetic pull: Smooth hover shift calculations pulling interactive items to pointers.
